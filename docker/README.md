## Swagger UI

Start Swagger UI:
```bash
docker compose -f docker/docker-compose.swagger.yml up
```

Swagger UI:
```
http://localhost:8081/#/
```

Stop:
```bash
docker compose -f docker/docker-compose.swagger.yml down
```
