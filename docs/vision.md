# Видение проекта

Документ описывает назначение Chat, его продуктовые принципы и критерий успеха.
Текущая реализация и ближайшая последовательность работ фиксируются в
`ROADMAP.md`; идеи за пределами принятого объёма — в `FEATURE_DESIGN.md`.

## Продукт

Chat — небольшой самостоятельно развёртываемый мессенджер для личных и
групповых переписок. Пользователи общаются через веб-интерфейс, получают новые
сообщения в реальном времени и могут вернуться к сохранённой истории.

## Принципы продукта

- **Сначала надёжная переписка.** Отправка, получение и сохранение сообщений
  важнее количества дополнительных функций.
- **Продуктом должно быть удобно пользоваться.** API нужен для ясной границы
  backend, но основным пользовательским интерфейсом остаётся веб-приложение.
- **Самостоятельное развёртывание.** Базовое использование не должно зависеть
  от обязательного внешнего SaaS.
- **Постепенное развитие.** Каждая законченная версия должна поддерживать
  работающий сценарий общения.
- **Честные обещания.** Безопасность, надёжность и доступность описываются в
  соответствии с реально реализованными гарантиями.

Первая версия ограничена текстовыми личными и небольшими групповыми диалогами.
Звонки, каналы, боты, мобильные приложения и сквозное шифрование в неё не
входят. Это границы начального объёма, а не запрет на пересмотр продуктового
направления в будущем.

## Инженерная цель

Chat — также практический проект для изучения Go и разработки полноценного
backend-приложения: от проектирования и тестирования до развёртывания и
сопровождения.

Технические решения должны решать подтверждённые задачи продукта и оставаться
понятными. Go-конкурентность, архитектурные шаблоны и
инфраструктура применяются по необходимости, а не ради демонстрации технологий.

## Критерий успеха

Chat успешен, если его можно самостоятельно развернуть и использовать для
повседневных переписок: пользователь может войти, начать диалог, отправить
сообщение, получить новое сообщение и позднее открыть историю. Проект должен
оставаться понятным и поддерживаемым, а его документация — соответствовать
реальному поведению.
