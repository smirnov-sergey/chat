# Frontend Design

Документ фиксирует проектируемые границы пользовательского интерфейса Chat и
принятые решения по мере их появления. Фактическая архитектура будет отражена
здесь по мере реализации frontend.

Публичным контрактом backend остаётся `openapi.yaml`. 
Предметные понятия и инварианты описаны в `DOMAIN_MODEL.md`,
а направления развития продукта — в `vision.md` и `FEATURE_DESIGN.md`.

# Принципы выбора технологий

Зависимости выбираются в следующем порядке:

1. встроенные возможности TypeScript, браузера и Web APIs;
2. встроенные возможности Vue;
3. официальные пакеты экосистемы Vue;
4. внешняя open-source библиотека под конкретную подтверждённую задачу.

Проект не должен зависеть от обязательного внешнего SaaS для сборки, запуска или хранения пользовательских данных.

Типы генерируются в `frontend/src/shared/api/schema.d.ts`; файл не редактируется вручную.

Типы обновляются командой `npm run api:generate`, а `npm run api:check` в CI
проверяет их соответствие текущей спецификации. Изменение API выполняется в
порядке:

```text
backend contract and OpenAPI
        │

generated TypeScript types
```
