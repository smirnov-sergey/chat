# Architecture

Документ описывает фактическую архитектуру Chat: основные компоненты, их ответственность и направления зависимостей.

Цель — простая и понятная архитектура приложения без абстракций, для которых пока нет практической необходимости.

---

# Архитектурные принципы

При разработке проекта соблюдаются следующие принципы:

- явные зависимости и Dependency Injection;
- разделение HTTP, бизнес-логики и хранения данных;
- небольшие интерфейсы в пакетах-потребителях;
- композиция вместо наследования;
- минимальное количество глобального состояния;
- стандартная библиотека Go там, где она адекватно решает задачу;
- архитектурные решения исходят из существующих сценариев, а не из гипотетического будущего.
