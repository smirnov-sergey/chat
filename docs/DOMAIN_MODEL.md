# Domain Model

Документ описывает предметную область Chat: основные понятия, отношения между ними, жизненные циклы и действующие бизнес-инварианты.

Здесь фиксируется смысл системы, а не способ её реализации. 
SQL-схема, структура Go-пакетов и HTTP endpoints описываются соответственно в migrations, `ARCHITECTURE.md` и `openapi.yaml`.

Документ отражает только реализованное поведение. 
Будущие идеи находятся в `FEATURE_DESIGN.md` и `ROADMAP.md`.
