# Roadmap

Roadmap показывает текущее состояние и только ближайший шаг. Следующий шаг
добавляется после завершения предыдущего.

## Текущий статус

Создан начальный HTTP-сервер. В репозитории есть черновая документация и заготовки
Docker-конфигурации и OpenAPI.

Реализованы:

- [x] Go-модуль `chat` с минимальной версией Go 1.26.9;
- [x] локальный HTTP-сервер и `GET /health`;
- [x] тесты HTTP-ответа, неизвестного пути и неподдерживаемого метода.
- [x] обработка остановки, ожидание активных HTTP-запросов до 10 секунд
  и принудительное закрытие соединений по таймауту;
- [x] добавлены тесты жизненного цикла сервера; запуск проверок выполняет разработчик.
