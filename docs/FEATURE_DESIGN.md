# Future Design

Этот документ сохраняет идеи и возможные направления развития Chat. 
Он не заменяет описание текущей реализации и не является списком ближайших задач.
Разделы кратко фиксируют существующий baseline только там, где без него нельзя понятно отделить уже принятое решение от будущей возможности.

Продуктовое видение изложено в `vision.md`. Текущий статус и порядок разработки — в `ROADMAP.md`.
Здесь фиксируются варианты, которые стоит учитывать при принятии будущих решений, но не нужно реализовывать заранее.
